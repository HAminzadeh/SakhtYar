# داده مرجع مصنوعی فاز ۵

تمام اعداد این فایل **ساختگی** هستند و نه قیمت بازار، نه نص قانون و نه توصیه سرمایه‌گذاری محسوب می‌شوند. واحد مالی: IRR. مبنای Golden مستقل از موتور Java، با Decimal و گردکردن HALF_UP محاسبه شده است. مقایسه مبلغ‌ها پس از گردکردن به ۲ رقم اعشار با tolerance صفر انجام می‌شود؛ ROI با شش رقم اعشار. آزمون‌های دسترسی نیز باید با نقش PostgreSQL محدود، Workspace واقعی TEST و شواهد HTTP انجام شوند.

- درآمد: ۳۰۰ × ۲۰٬۰۰۰٬۰۰۰ = ۶٬۰۰۰٬۰۰۰٬۰۰۰
- کل هزینه: ۳٬۶۰۰٬۰۰۰٬۰۰۰ + ۲۰۰٬۰۰۰٬۰۰۰ + ۱۰۰٬۰۰۰٬۰۰۰ + ۱۰۰٬۰۰۰٬۰۰۰ = ۴٬۰۰۰٬۰۰۰٬۰۰۰
- سود: ۲٬۰۰۰٬۰۰۰٬۰۰۰ و ROI = ۵۰٪
- افزایش قیمت فروش ۱۰٪ و هزینه پایه ساخت ۲۰٪: درآمد = ۶٬۶۰۰٬۰۰۰٬۰۰۰ و کل هزینه = ۴٬۷۲۰٬۰۰۰٬۰۰۰ و سود = ۱٬۸۸۰٬۰۰۰٬۰۰۰
- از روی سند مرجع مصنوعی هیچ نتیجه حقوقی/فنی برای یک ملک واقعی استخراج نکنید.
