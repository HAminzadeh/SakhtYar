# V2 Foundation
Backend target: controller -> service -> repository -> entity.
REST uses request/response DTOs and MapStruct; entities are never exposed directly.
Ant Design is the V2 design system; MUI remains temporarily during incremental migration.
Language boundary: User -> Language Agent -> Canonical XML -> XSD -> Intent Router -> Domain Services.
V2 platform work adds observability, versioned platform APIs, webhooks, and Phase 4 urban intelligence.
