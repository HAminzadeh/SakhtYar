# راهنمای اجرای پایه شبیه‌ساز

- صفحه مدیریتی `/admin/simulations` صرفاً برای `USER_MANAGE` در دسترس است.
- فضای آزمایشی ایجاد کنید. این کار فقط در `simulation_workspace` و `simulation_audit` می‌نویسد.
- «ثبت بررسی ایمن» را اجرا کنید. این کار یک `simulation_run` با ۲۴ `simulation_result` با حالت `BLOCKED` ایجاد می‌کند. **هیچ رکورد تجاری TEST تولید نمی‌کند.**
- در بخش شواهد، شمارش ردیف‌های نشان‌دار TEST در جداول پشتیبانی‌شده نمایش داده می‌شود. شمارش صفر کاملاً طبیعی است.
- گزارش JSON را ذخیره کنید؛ در گزارش، گیت امنیتی و دلیل اجرا نشدن مشخص است.
- قبل از راه‌اندازی برنامه و اعمال V58 از PostgreSQL بک‌آپ واقعی بگیرید. فایل Flyway بعد از اجرا نباید ویرایش یا پاک شود.
- حالت REAL تمامی صفحات موجود بدون تغییر باقی می‌ماند. نمای سراسری TEST و اجرای دارای نوشتن تا تکمیل حفاظت RLS/FK/Side Effects غیرفعال است.

## نکات دسترسی

این زیرساخت در همان دیتابیس عملیاتی ثبت می‌شود، اما مسیر مدیریت شبیه‌ساز فقط به مدیر دارای `USER_MANAGE` اختصاص دارد. فیلترهای نمای TEST صرفاً برای APIهای شبیه‌ساز اعمال شده‌اند؛ این را با ایزوله‌بودن همه ماژول‌ها اشتباه نگیرید.
