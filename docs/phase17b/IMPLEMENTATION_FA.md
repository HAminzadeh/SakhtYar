# فاز ۱۷-B — راهنمای فنی و عملیاتی

مبنای ساخت: `f8578f0fa2aff8aea0a2710018919f6aec9e8bfe` در شاخه `v2`، تاریخ ۲۶ نوامبر ۲۰۲۶. آخرین Migration در زمان ساخت: V68.

## مهم‌ترین اصلاحات

- تصمیم FAR و سطح اشغال با مقایسه حاصل‌ضرب دقیق `BigDecimal` انجام می‌شود؛ مقدار تقسیم‌شده فقط نمایشی است.
- شرط و استثنای ناشناخته با `REVIEW` متوقف می‌شود، نه PASS پیش‌فرض.
- تغییر مؤثر Rule، شناسه Evidence قبلی را خالی می‌کند و Rule را غیرفعال می‌کند.
- انتخاب Rule مجاز در EvidenceService باید مقدار/نوع/واحد/عملگر Rule را با سند تأییدشده در همان زمان تطبیق دهد.
- تفاوت دو حد در یک محدوده مشترک، Conflict است و Rule اول صرفاً به دلیل Priority برنده نمی‌شود.
- Snapshot فعلی با امکانات JSONB موجود نگهداری می‌شود؛ بدون تغییر Schema.
- `KnowledgeGovernanceService.publish` اجزای Release را خودکار COMPATIBLE نمی‌کند؛ انتشار با منشأ نامعتبر یا تأییدکننده یکسان رد می‌شود.
- مسیرهای Preview جدید برای Binding و انتشار افزوده شده‌اند؛ هیچ‌کدام خودکار DML نمی‌کنند.
- `municipalityInputs` در مواجهه با حدهای متناقض فیلد را حذف و `conflictingFields` برمی‌گرداند.

## دستور نصب

ZIP و PS1 را در Downloads قرار دهید. سپس حالت‌های `SelfTest`, `Audit`, `DryRun`, `ApplySource`, `Verify` را به ترتیب اجرا کنید. اسکریپت Git HEAD و Blobهای tracked و SHA256 را بررسی می‌کند؛ روی اختلاف متوقف می‌شود. در صورت نیاز Rollback با مسیر Backup ثبت‌شده اجرا می‌شود.

## محدودیت‌های آگاهانه

- وضعیت بانک قوانین در آخرین ممیزی کاربر: ۹ Rule نامزد، صفر Verified، صفر Release منتشرشده و صفر UrbanRule. این آمار صرفاً تاریخی است.
- نسخه‌بندی دائمی Rule در Ledger جدا، حل حقوقی تعارض، اجرای شرط/استثنای حقوقی و Batch binding هنوز Gate بسته دارند.
- سناریوها global هستند و انتساب case به Scenario از مدل موجود قابل اثبات نیست.
- هیچ قانون، سند یا داده REAL توسط این بسته تأیید، منتشر، ویرایش یا وارد دیتابیس نمی‌شود.
- Maven / JUnit و کلون Postgres / RLS / E2E در محیط ویندوز کاربر باید تأیید شوند.
- Read-only SQL همراه بسته برای اندازه‌گیری وضعیت واقعی وجود دارد.
