# الگوهای Spring Boot

> این فایل یک دستورالعمل متنی قابل‌استفاده در ChatGPT است؛ اسکریپت یا افزونه اجرایی نیست.

## کاربرد در ساخت‌یار
تفکیک Controller/Service/Repository/DTO، مدیریت Validation و Transaction.

## ورودی‌ها
- شرح درخواست، محدودیت، فایل‌ها و شواهد واقعی
- بخش‌های مرتبط با Java/Spring Boot، React/TypeScript یا فرایند دانش

## گردش‌کار
- ۱. دامنه کار و معیار موفقیت را مشخص کن.
- ۲. ورودی و فایل‌های واقعی قابل‌دسترسی را بررسی کن.
- قرارداد DTO، لایه Service، اعتبارسنجی و Transaction را بررسی کن.
- ۴. ریسک و آزمون پذیرش را تعریف کن.
- ۵. خروجی را با برچسب «تأییدشده/پیشنهادی/اجرا‌نشده» ارائه کن.

## خروجی
تغییر پیشنهادی و ماتریس تست backend

## مراقبت‌های مهم
رفتار تولیدی و API قبلی باید حفظ شود.
- هیچ ادعای اجرای تست، ذخیره، Push یا تغییر فایل بدون ابزار و تأیید موفقیت مطرح نکن.
- برای عملیات قانونی و مقرراتی، منشأ و بازبینی کارشناس را الزامی بدان.

## نمونه درخواست
> برای پروژه ساخت‌یار از روش «الگوهای Spring Boot» استفاده کن. فقط شواهد و فایل‌های ارائه‌شده را مبنا قرار بده؛ مراحل را روشن و خروجی قابل بررسی بده.
