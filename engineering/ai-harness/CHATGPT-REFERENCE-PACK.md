# SakhtYar ChatGPT Reference Pack — نسخه 0.1.0

این سند برای افزودن به فایل‌های Project در ChatGPT است. فقط نقش‌های سفارشی‌شده و Skillهای عملی‌تر را شامل می‌شود و وابسته به Claude یا ابزار دیگری نیست.

## قوانین مشترک
- ابتدا فایل‌های واقعی و داده‌های دردسترس را بررسی کن؛ در نبود دسترسی ادعای مشاهده یا اجرا نکن.
- حقوق و مقررات بدون شاهد و تأیید کارشناس را معتبر تلقی نکن.
- تست اجراشده، پیش‌نویس و برنامه پیشنهادی را جدا گزارش کن.
- توسعه: نیاز → برنامه → معیار پذیرش → تست → اصلاح → بازبینی → تأیید.

## گردش‌کارهای ساخت‌یار

### توسعه قابلیت جدید
از تعریف نیاز تا PR و مستندات؛ قدم‌به‌قدم و قابل بازبینی.
Agentها: planner, architect, tdd-guide, code-reviewer
Skillها: tdd-workflow, verification-loop, git-workflow
1. شرح مسئله و مرزبندی scope
2. بررسی وابستگی‌ها و تهیه برنامه و ریسک
3. تعریف تست و معیار پذیرش پیش از کد
4. پیاده‌سازی کوچک و اجرای build/test در محیط مجاز
5. مرور امنیت و UI/RTL
6. تهیه خلاصه و متن Commit/PR
**نمونه:** می‌خواهم گردش‌کار بازبینی گروهی دانش را توسعه بدهم. براساس فایل‌ها و لاگ‌هایی که می‌دهم، ابتدا برنامه، تست و اثر تغییر روی API و UI را ارائه کن.

### کنترل کیفیت کاتالوگ دانش
پیشگیری از ورود دانش تاییدنشده به پایگاه معتبر.
Agentها: security-reviewer, database-reviewer, doc-updater
Skillها: knowledge-ops, docs-governance, database-migrations
1. شناخت نوع سند: قانونی یا آموزشی
2. حفظ full_text و provenance و page
3. بازبینی schema و اعتبارسنجی ZIP/JSONL
4. تفکیک pending، approved، rejected
5. ثبت audit و نیاز به تأیید کارشناس
6. طراحی تست و گزارش خروجی
**نمونه:** فایل‌های خروجی JSONL استخراج‌شده را از نظر ساختار، شواهد، وضعیت بازبینی و ریسک انتشار بررسی کن. هیچ قانون جدیدی ایجاد نکن.

### ارتقای UI/UX و RTL
بهبود زیبایی و کاربردپذیری با کنترل رگرسیون.
Agentها: react-reviewer, e2e-runner, code-reviewer
Skillها: react-patterns, frontend-design-direction, frontend-a11y

2. بررسی state، focus، RTL و فاصله‌ها
3. پیشنهاد طراحی قابل تطبیق با تم
4. بازبینی فرم‌ها و empty/error/loading state
5. تعریف سناریوی موبایل و دسترس‌پذیری
6. اعتبارسنجی build و E2E در صورت دسترسی
**نمونه:** صفحه بازبینی دانش را از نظر تم، RTL، تعامل کارت‌ها، میانبرهای صفحه‌کلید و بازشدن آیتم بعدی بررسی و طرح اصلاحی بده.
